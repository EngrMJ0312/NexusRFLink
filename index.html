📖 Pattern formulas — antenna theory basis
  • Omni: uniform azimuthal radiation (vertical half-wave dipole H-plane)
  • Yagi: 6-element end-fire array factor for main lobe shape, AF(ψ)=sin(Nψ/2)/(N·sin(ψ/2)), λ/4 spacing; back lobe floored at 16 dB F/B (literature-typical 13–20 dB — a uniform array alone gives an unphysical perfect null, since real Yagis use asymmetric element lengths)
  • Dish: exact uniform circular aperture far-field, |2J₁(x)/x|² (x=k·a·sinθ) — first null at x=3.8317, first sidelobe −17.6 dB
  • Standard far-field antenna theory equations, consistent with Balanis, Antenna Theory: Analysis and Design, 4th ed. — cross-checked against independent academic sources.

EIRP — Effective Isotropic Radiated Power
IEEE Std 149 Lab Experiment 1
General Formula
EIRP (dBm) = Ptx (dBm) − Lcable (dB) + Gtx (dBi)
● LIVE EIRP = — − — + — = — dBm

Step-by-step Procedure
1
Measure TX output power Ptx at the radio port using a calibrated spectrum analyzer or power meter.
P_tx = reading + cable_loss_to_meter
2
Measure or look up every cable segment loss and sum them: coax run, lightning arrestor, combiner, connector pairs.
L_total = Σ(α_i · l_i) + N_conn · 0.3 dB
3
Obtain antenna gain from datasheet or measure with antenna range. Confirm polarization and frequency match.
G_tx = datasheet gain at operating frequency
4
Compute EIRP. Compare against regulatory EIRP limit for your frequency band and jurisdiction.
EIRP = P_tx − L_cable + G_tx
🔬 Lab Experiment 1 — EIRP Measurement
  • ▸Connect spectrum analyzer to TX antenna port via calibrated attenuator.
  • ▸Record P_tx at the target frequency. Note analyzer reference level.
  • ▸Replace attenuator with the actual cable run. Record the new reading. The delta is L_cable.
  • ▸Substitute into EIRP formula. Compare with antenna datasheet EIRP estimate.
  • ▸Expected result: EIRP should match theoretical within ±1 dB.

🔬 Lab Experiment 2 — Path Loss Measurement
  • ▸Place TX and RX antennas at a known separation (start 1 m, then 2 m, 4 m, 8 m).
  • ▸Record P_rx at each distance using a spectrum analyzer or signal-level meter.
  • ▸Calculate measured path loss: PL_measured = EIRP − P_rx + G_rx.
  • ▸Plot measured vs theoretical FSPL. Slope should be 20 dB/decade.
  • ▸Deviation at short ranges: near-field effects. At long ranges: multipath or obstruction.
🛠 Equipment Required
Signal Generator (TX)Spectrum Analyzer (RX) Calibrated Antennas (matched pair)Tape Measure / Laser Tripods (antenna height control)RF Absorber (anechoic range)
TIP: Ensure antennas are in each other's far field before measuring. Far-field distance: d_ff = 2D² / λ, where D is the largest antenna dimension.

🔬 Lab Experiment 4 — Noise Figure Measurement (Y-factor method)
  • ▸Connect a calibrated noise source (known ENR) to the DUT (LNA or receiver) input.
  • ▸Measure output power with noise source ON (P_hot) and OFF (P_cold).
  • ▸Y-factor: Y = P_hot / P_cold (linear ratio)
  • ▸Noise Figure: NF = ENR (dB) − 10·log₁₀(Y − 1)
  • ▸Verify result against DUT datasheet NF specification.

🔬 Lab Experiment 5 — Fresnel Diffraction Loss
  • ▸Set up a bench-top RF link at known distance. Confirm free-space P_rx first.
  • ▸Calculate F1 radius at midpoint using r₁ = 0.5·√(λ·d).
  • ▸Introduce a flat metal obstruction at midpoint. Start 1.2·r₁ above LOS (no effect). Lower in 0.1·r₁ steps.
  • ▸Record P_rx at each position. Plot diffraction loss vs. Fresnel obstruction ratio.
  • ▸At 0.6·r₁ clearance, expect ~0 dB loss. At 0 (LOS tangent), expect 6 dB loss.

🔬 Lab Experiment 6 — Sensitivity & Margin Measurement
  • ▸Configure receiver for a known modulation (e.g. QPSK, target BER 10⁻⁶).
  • ▸Using signal generator, sweep input power from −50 dBm down in 1 dB steps while monitoring BER.
  • ▸The input power level at which BER crosses 10⁻⁶ is the measured sensitivity.
  • ▸Compare with calculated: Sensitivity = N₀ + NF + SNR_req.
  • ▸The link margin = actual P_rx during field test − measured sensitivity.

ITU-R / 3GPP

2. Two-Ray Ground Reflection
PL2ray = 40·log10(d) − 20·log10(htx) − 20·log10(hrx)
Valid beyond crossover distance: dcross = 4·htx·hrx / λ
Below crossover: use FSPL. Slope changes from 20 to 40 dB/decade at crossover.
